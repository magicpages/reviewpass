# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be decent to people. Assume they are acting in good faith, argue about
the code rather than the person writing it, and accept that a maintainer may say
no to something you spent real effort on.

Report unacceptable behaviour by opening a private security advisory, which is
the only private channel this repository has. Reports are handled by the
maintainers and kept confidential.
